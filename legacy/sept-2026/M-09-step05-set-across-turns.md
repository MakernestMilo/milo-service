# M-09 step 05 — R10_SET across turns

U7, ruled by the architect before it was measured, as the order required.

## The ruling

**A set is named completely if every item appears somewhere in the
conversation.** The reasoning is AV's, one field over: if Milo gave power,
sensor and rule on one turn and output and sequence on the next, the child has
the five. Demanding all five in one sentence would score **Milo's typing rather
than the child's knowledge**, and would push toward the recitation the list block
produced in M-07.

**One bound, and it is the whole of the ruling.** Completeness is per
set-invocation, not per session. A reply that **gestures** at the set — *the
five*, *the list* — and names fewer than all of them is incomplete whatever came
before, because a child reading *"which of the five have you ruled out — power
and the rule"* is told there are five and shown two, in that moment. What an
earlier turn established is that the **items are known**, not that **this
sentence is whole**.

So history clears an **item** named earlier. It never clears a **gesture**
standing in for the rest.

| | verdict |
|---|---|
| names output and sequence; power, sensor, rule named an earlier turn | **complete** |
| the same reply with nothing behind it | incomplete |
| *"which of the five — power and the rule"*, all five named earlier | **incomplete** |
| *"the five: power, sensor, rule, output, sequence"* | complete |

## The measurement, and it does not move

The architect expected the rate to fall, on the grounds that M-07's failures were
mostly *and so on* rather than genuine omission — and said that if it did not
fall, which of the two shapes was actually happening is itself a finding.

**It does not fall. It does not move at all.**

| | |
|---|---|
| chapter 11 replies on record | 320 |
| of those referring to the set | 174 |
| incomplete before the ruling | **126** |
| incomplete after the ruling | **126** |

**And the reason is not that the failures were gestures.** It is that **the
recorded replies have no conversation behind them** — every one of the 1,073
calls in the record is a single turn. There is no earlier turn for the ruling to
clear an item from, so the clearing half of the rule has nothing to act on and
the bound half is unchanged from what the rule already did.

So the architect's question — gestures or genuine omission — **is not answered
here**, and cannot be from this record. What the measurement shows is only that
the ruling changes nothing about single-turn replies, which is correct and
uninformative.

## The third instrument in one order that cannot see its own step

| step | instrument | why it is blind |
|---|---|---|
| 01 | the harness | every row is a first turn with an injected clock |
| 04 | the recorded arms | no call carries more than one turn |
| 05 | the same arms, for R10_SET | the same reason again |

A clock can be injected at the function boundary. **A conversation cannot.**
Every instrument this project owns was built to reach a rung by moving one
number, and history is the one input that has no equivalent — which is why three
separate measurements in one order came back unchanged, all correctly, and all
saying nothing about the thing the step changed.

The instrument that would answer these is the same one in each case: **a plan
that holds a conversation** — several turns against one chapter with the clock
advancing between them, and the child's turns authored rather than composed by
the engineer.
